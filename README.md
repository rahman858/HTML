# Product Manager App

Aplikasi web satu halaman (SPA) untuk mengelola data produk menggunakan **DummyJSON API** dengan metode HTTP: POST, PUT, DELETE.

## Cara Membuka Aplikasi

### Prasyarat
- Web browser (Chrome/Firefox/Edge)
- Koneksi internet

### Langkah-langkah

**Cara 1: Langsung Buka File**
1. Download atau clone repository ini
2. Buka folder `product-manager-app`
3. Double klik file `index.html`
4. Aplikasi akan terbuka di browser

**Cara 2: Menggunakan Live Server (Rekomendasi)**
1. Buka folder project di Visual Studio Code
2. Install ekstensi "Live Server"
3. Klik kanan `index.html` → "Open with Live Server"
4. Aplikasi berjalan di `http://localhost:5500`

**Cara 3: Mengakses Online (Jika sudah di-deploy)**
- Buka: `https://[username].github.io/product-manager-app`

## Fitur
- ➕ Tambah produk (POST)
- ✏️ Edit produk (PUT)
- 🗑️ Hapus produk (DELETE)

## Teknologi
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Fetch API
- DummyJSON API

## Catatan
Data tidak permanen karena menggunakan **mock API**. Refresh halaman akan mengembalikan data awal.
