# 📦 Product Manager App

Aplikasi web satu halaman (SPA) untuk mengelola data produk menggunakan **DummyJSON API**.

## ✨ Fitur

- ✅ **Tambah Produk** (POST)
- ✅ **Edit Produk** (PUT)
- ✅ **Hapus Produk** (DELETE)
- ✅ Error handling dengan tampilan di UI
- ✅ async/await (tanpa .then)
- ✅ Responsive design

## 🚀 Cara Menjalankan

1. Simpan semua file dalam satu folder
2. Buka `index.html` menggunakan browser
3. Atau gunakan Live Server di VS Code
